# Semantic Navigator

Transform Power BI semantic models into business-friendly documentation.

## Features

- Semantic Model Extraction
- Data Dictionary Generation
- Measure Catalogue Creation
- Lineage Analysis
- AI-Generated Definitions
- Business Ontology Generation

## Privacy

Semantic Navigator processes models locally.

No semantic models are stored.

No metadata is retained.

Users are responsible for validating generated documentation.
